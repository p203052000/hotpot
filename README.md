# 巷口火鍋

寒流來了，外面下著冷雨。掀開暖簾，裡面有一鍋正在滾的湯。

一個在瀏覽器裡玩的火鍋遊戲。湯面用 WebGL 即時運算，食材紋理、蒸氣與大部分聲音都是程式生成的。單一 HTML 檔，不需要安裝，手機也能玩。

## 怎麼玩

- 點菜單，食材會下到鍋裡。鴛鴦鍋可以選要下到哪一邊。
- 拖著食材在湯裡涮，肉片涮一涮熟得特別快。
- 丸子和餃子先沉下去，浮起來就熟了；蛤蜊要等它打開。
- 拖到右下角的碗就是吃掉。先在醬料台調一碗醬，幸福值會加成。
- 煮肉會冒浮沫，在湯面上滑動就能撈掉。湯少了記得加湯。
- 吃到飽足度滿，就會收到一張「火鍋日記」。

## 內容

- 鍋底：麻辣、昆布、番茄、酸菜白肉、牛奶、沙茶（和朋友吃是鴛鴦鍋）
- 50 種火鍋料：霜降牛、毛肚、白蝦、蛤蜊、貢丸、蛋餃、鴨血、凍豆腐、茼蒿、芋頭、王子麵、冬粉、雞蛋⋯⋯
- 醬料台：12 種醬料，調出台式經典、沙茶蛋黃、川味油碟等組合
- 8 種飲料：生啤酒、台灣啤酒、酸梅湯、冬瓜茶、豆奶、蘋果西打、嗨棒、烏龍茶
- 天氣：雨夜、雷雨、下雪、晴夜；吃法：一個人吃，或和朋友一起
- 聲音：由一顆顆氣泡合成的滾煮聲，火越大泡泡越密；鴛鴦鍋兩邊分在左右聲道

建議戴耳機。

## 在本機開啟

直接用瀏覽器打開 `index.html` 即可。

## 用 GitHub Pages 發布

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存後幾分鐘就會有網址。
